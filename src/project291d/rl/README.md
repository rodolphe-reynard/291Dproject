# Reinforcement Learning for Bridge Maintenance Control

## 1. Overview

This module implements a Q-learning-based maintenance decision system for the Z24 Bridge project.

The agent receives a predicted damage severity score between 0 and 1 and selects one of four maintenance actions to minimize long-term maintenance costs and structural risk.

**Current status:** The RL agent has been implemented and tested using a simplified mock environment. The environment parameters are assumptions and will be replaced or calibrated when the final simulation environment is available.

## 2. Project Structure

```text
rl/
├── mock_environment.py   # Simulated bridge environment
├── reward.py             # Maintenance costs and reward calculation
├── q_learning.py         # Tabular Q-learning agent
├── train_rl.py           # Model training
├── evaluate_rl.py        # Policy evaluation
└── README.md
```

## 3. Model Definition

**Input:** Predicted severity score (0–1).

**Actions:**

| ID  | Action        |
| --- | ------------- |
| 0   | Do nothing    |
| 1   | Inspect       |
| 2   | Restrict load |
| 3   | Repair        |

**Objective:** Minimize cumulative maintenance costs and structural damage risk.

The agent learns a decision policy through repeated interactions with the environment.

## 4. Training

Run from the project root:

```bash
python -m project291d.rl.train_rl
```

Default configuration:

- Algorithm: Tabular Q-learning
- Training episodes: 10,000
- Severity discretization: 20 bins
- Actions: 4

The trained Q-table is saved as:

```text
outputs/q_table.npz
```

## 5. Evaluation

Run:

```bash
python -m project291d.rl.evaluate_rl
```

The evaluation compares Q-learning against three baseline policies:

- Never act
- Periodic inspection
- Fixed severity threshold

### Preliminary Results

Results from 500 evaluation episodes using the mock environment:

| Policy           | Mean Total Cost | Mean Risk Cost | Mean Repairs |
| ---------------- | --------------: | -------------: | -----------: |
| Q-learning       |           93.69 |          50.02 |         0.00 |
| Never act        |          170.26 |         170.26 |         0.00 |
| Periodic inspect |          182.88 |         172.88 |         0.00 |
| Fixed threshold  |           99.58 |          62.93 |         0.30 |

Q-learning reduced total simulated cost by approximately 45% compared with the Never Act baseline.

### Learned Action Distribution

| Action        | Frequency |
| ------------- | --------: |
| Do nothing    |    77.09% |
| Inspect       |     0.10% |

## 6. Limitations and Future Work

- The current environment uses assumed damage progression and maintenance costs.
- Severity scores are simulated rather than generated by the final classifier.
- The model rarely selects inspection and never selects repair under the current assumptions.
- The reward function and state transitions require further validation.
- Future work includes integration with the team's environment, sensitivity analysis, and evaluation under different severity and cost assumptions.

**Note:** These preliminary results demonstrate the RL implementation under simulated conditions. They do not establish real-world bridge maintenance performance.
